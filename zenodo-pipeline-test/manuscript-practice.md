# Team Manuscript Practice Draft

This file is for team practice editing in GitHub.

**Citation/format style for this draft: APA 7th edition**

## Quick Formatting (No memorization needed)
- **Bold**: type `**text**` → **text**
- *Italic*: type `*text*` → *text*
- ***Bold + italic***: type `***text***` → ***text***
- Link: type `[title](https://example.com)` → [title](https://example.com)
- Bullet list: start line with `- `
- Numbered list: start line with `1. `
- Checkbox: type `- [ ]` (unchecked) or `- [x]` (checked)

Tip: if you're in GitHub's editor, you can often highlight text and use keyboard shortcuts:
- Bold: **Ctrl/Cmd + B**
- Italic: *Ctrl/Cmd + I*

## Section G: References (APA 7th)

Journal article template:  
Author, A. A., & Author, B. B. (Year). Title of the article. *Title of Journal, 12*(3), 45–67. https://doi.org/xx.xxx/yyyy

Book template:  
Author, A. A. (Year). *Title of the book*. Publisher.

Webpage template:  
Author, A. A. (Year, Month Day). Title of page. *Site Name*. URL

In-text citation examples:  
- Narrative: Author (Year)  
- Parenthetical: (Author, Year)  
- Direct quote: (Author, Year, p. 10)
